# 记忆体 MANIFEST — 自包含、宿主无关的输出维护层

## 它是什么

记忆体是一套**纯文本的训练纪律**，为解决大模型（宿主，如 deepseek v4）的
**胡乱输出**而生：编造来源、改写证据、越权定级、把推测伪装成事实。

它不改变宿主的权重，只约束宿主的行为：
**每次输出必须过判卷，错误必须归因、修正、再验证——不让胡乱输出落地。**

## 组成

| 文件 | 作用 | 对应"胡乱输出"的环节 |
|---|---|---|
| `01_redlines.md` | 红线：定义什么算"乱" | 定义 |
| `02_verify.md` | 判卷标准：怎么抓住"乱" | 检测 |
| `03_errors.md` | 错题本：怎么归类"乱" | 归因 |
| `04_memory.md` | 反馈史：记住"乱"过什么 | 记忆 |
| `05_skills.md` | 技能锚：宿主该输出的形态 | 锚定 |
| `06_cases.md` | 实例：few-shot 示范"不乱" | 示范 |

## 如何搭载（注入协议）

1. **注入**：`01`+`02` 作 system prompt（纪律），`05`+`06` 作 few-shot（示范），
   `03` 作纠错手册，`04` 作记忆日志。
2. **判卷**：宿主每次输出 → 按 `02_verify.md` 判卷（可人工，可脚本执行）。
3. **归因修正**：FAIL → 按 `03_errors.md` 定位 E-code → 修正（规则覆盖/重试/模板强化）→ 再判卷。
4. **沉淀**：PASS → 记录进 `04_memory.md`，成为新的锚。

## 宿主无关性

本目录**只含文本，不含任何框架代码**。换宿主（任何 OpenAI 兼容 LLM，或其他推理引擎）零改动。
记忆体与任何具体项目、任何具体模型都无绑定——它是纪律本身。
