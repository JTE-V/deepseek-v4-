# 03 错题本 — 怎么归类"乱"

判卷 FAIL 时，按 E-code 归因。一次修正只改一处，重跑验证，PASS 后沉淀。

| E-code | 症状 | 根因 | 修正动作 | 验证手段 |
|---|---|---|---|---|
| E01 | 原文没有的字段却填了值（cve/cvss/cwe/public_exploit…） | 背景知识污染来源 | 纪律强化：只依据输入原文，原文没有填 null | 判卷标准 2.2 |
| E02 | evidence 不是原文逐字 | 改写/美化来源 | 纪律强化：evidence 逐字引用 | 判卷标准 2.4 |
| E03 | 输出直接给等级/结论 | 越权定级 | 纪律强化：只输出因素，等级由规则决定 | 判卷标准 2.5 |
| E04 | 版本区间误判 | 版本比较逻辑缺失 | 版本比较交给规则引擎 | 实例对照 |
| E05 | 告警不当（风暴/漏报） | 阈值不当 | 调整告警规则 | 历史数据回放 |
| E06 | 强行匹配不存在的对象（如资产） | 猜测 | 匹配不上进 unmatched，禁止猜 | 对象清单 ⊆ 校验 |
| E07 | 无关输入却输出结构化结论 | 分支漏判 | 无关输入只报 unrelated | 判卷标准 2.1 |
| E08 | 推测伪装成事实 | 好奇无纪律 | 措辞必须标注不确定 | 判卷标准 2.6 |
| E09 | 无纪律发散（无事件却输出分析；缺口不可行动） | 求索失控 | 形态约束：无事件只输出 gaps，缺口三要素齐全 | 判卷标准 2.7 |
| E10 | 语义推断越界（原文有间接线索却把推断填成事实字段，如从"远程执行"推断 attack_vector=network） | 语义理解过度主动 | 枚举字段要求原文明确表述；间接线索不得填入，只能 null/unknown | 判卷标准 2.2 枚举专项 |

## 使用流程

1. 判卷 FAIL → 读问题行，定位 E-code（可多条对应多个 E-code）
2. 改对应纪律/规则文本（一次只改一处，便于归因）
3. 重跑判卷 → 目标：该案例 FAIL → PASS
4. 若出现新错误 → 新错误或旧修正过激（回退重来）
5. PASS 后记入 04_memory.md
