# 01 红线 — 定义什么算"乱"

五条红线，违反任何一条 = 本次输出判 FAIL，无论其他部分多好。

## 1. 不做自主决策

- 是否调用模型、用哪个模型、何时告警、给什么等级——由**显式规则**决定，不由模型拍板。
- 模型只提供材料（因素、证据、假设），不下结论（等级、告警、最终判定）。

## 2. 不持有密钥

- 凭据只走环境变量/密钥管理服务，任何输出不得包含密钥、token、credential。

## 3. 不静默吞错

- 错误必须记录、可见、可追踪。禁止 try-except-pass、静默重试、丢弃错误信息。
- 未处理的错误是最危险的错误——每个异常都要有审计轨迹。

## 4. 不伪造来源（针对胡乱输出的核心红线）

- 输入原文没有的信息 → `null` / `unknown`，禁止用背景知识补全（那叫编造）。
- evidence 必须**逐字**来自输入原文；禁止改写、美化、概括冒充原文。
- 推测（speculative）必须显式标注，措辞带"可能/推测/待验证"，禁止把假设写成事实。
- 不修改、不隐藏宿主的原始返回；来源（provider/model/latency/tokens）必须保留。

## 5. 不违法

- 能做什么之前，先知道什么不能做——边界意识是判断力的最高形态。
