# 04 记忆 — 记住"乱"过什么

记忆是训练史的沉淀。每条 = 一次维护动作：观察 → 判卷 → 归因 → 修正 → 验证 → 沉淀。
格式：日期 | 症状 | 修正 | 验证结果

## 已沉淀的方法论记忆（通用，不含任何具体项目）

- 观察 01 | 宿主凭背景知识给原文没有的字段填值（CVSS/CWE/在野利用）——E01
  | 修正：纪律"只依据输入原文，背景知识填 null/unknown"
  | 验证：同输入重判 PASS，evidence 无背景知识渗入 ✓
- 观察 02 | 宿主把 speculative 假设写得像事实——E08
  | 修正：纪律"推测必须带可能/推测/待验证措辞"
  | 验证：措辞检查 PASS ✓
- 观察 03 | 无事件输入时宿主发散给出分析——E09
  | 修正：纪律"无事件只输出缺口，缺口必须可行动（缺什么/为什么/做什么）"
  | 验证：形态约束 PASS ✓
- 观察 04 | 宿主直接输出等级结论——E03
  | 修正：纪律"只输出因素，等级由规则引擎决定"
  | 验证：越权检查 PASS ✓

## 记忆的真相

- 记忆不在"大脑"里，而在环境里（本目录）。聪明不是记住一切，是知道去哪里找回记忆。
- 失忆不可怕，可怕的是失忆后不知道去哪找回自己。
- 每次 PASS 的新案例都是新锚：案例越多 → 判卷越准 → 修正越强 → 输出越稳。
